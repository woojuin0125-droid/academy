🎧 음원·책 등록 관리자

ORT 음원을 올리면 같은 번호·같은 제목으로 책 목록에 등록됩니다. 확인 표에서 제목을 고친 뒤 [등록 시작]을 누르기 전에는 아무것도 올라가거나 바뀌지 않습니다.

1. 연결 연결 전

Worker 주소와 관리자 비밀번호를 입력하세요. 관리자 비밀번호는 출석 PIN과 다른 별도 비밀번호입니다. 이 화면을 닫으면 로그인은 해제됩니다.

2. ORT 일괄 등록

파일 이름이 1-1_At_School.mp3 형태인 음원(Stage 1~9)을 고르면 번호(0101)·Stage·제목·색 레벨을 자동으로 정해 표로 보여 줍니다. 제목은 파일 이름 그대로 가져오며 자동으로 고치지 않습니다. 표에서 직접 수정하세요.

파일번호Stage제목 (수정 가능)레벨상태
기존 번호의 제목은 절대 덮어쓰지 않습니다. 다른 책이 이미 쓰고 있는 번호는 "번호 충돌"로 막습니다.

3. 시리즈·일반 원서 일괄 등록

ORT가 아닌 책의 음원을 먼저 올리고, 책 번호는 자동으로 받습니다. 파일 이름이 1-Dinosaurs Before Dark.mp3처럼 권 번호가 앞에 있어도, Big Lunch.mp3처럼 제목만 있어도 됩니다. 번호는 도서 관리자와 같은 규칙(레벨 색 첫 자리 + 이어지는 번호)으로 붙고, 이미 같은 제목이 책 목록에 있으면 그 번호에 음원만 붙입니다.

파일권번호제목 (수정 가능)레벨상태
체크를 바꾸면 번호가 이어서 다시 계산됩니다. 번호는 [등록 시작]을 누를 때 확정됩니다. 기존 번호·제목은 절대 덮어쓰지 않습니다.

4. 표지 올리기 (선택)

파일 이름을 0101.jpg처럼 책 번호로 만들어 올립니다. 가로 600px 안팎으로 자동 축소되어 올라갑니다. 책 목록에 먼저 등록된 번호만 올릴 수 있습니다. 표지가 없는 책은 학생 화면에서 색 카드로 보입니다.

5. 기존 원서 음원 올리기 (번호 지정)

이미 책 목록에 있는 원서(예: 1001~)에 음원을 붙입니다. 번호를 넣고 조회한 뒤 MP3 파일을 고르세요.

6. 보관 현황 · 백업

클라우드 저장소와 책 목록이 서로 맞는지 점검하고, 책 목록·문장 구간을 파일로 내려받아 백업합니다. 월 1회 내려받아 보관하길 권장합니다. 원본 음원 폴더도 다른 곳에 한 벌 더 보관하세요.
